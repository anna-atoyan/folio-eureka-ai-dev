## How to Create a Config for Your App

### Step 1: Find Your TestRail Section IDs

1. Log into TestRail
2. Navigate to your app's project (e.g., FOLIO Bug Fest)
3. Click on each section in the left panel
4. Note the section ID from the URL or section properties

### Step 2: Create a Config File

Save as `references/config/YOUR-APP.md` and fill in:

```markdown
# YOUR-APP TestRail Config

Generated by: [Your name]  
Last updated: [Date]

## Project Info

| Property | Value |
|----------|-------|
| TestRail Project | FOLIO Bug Fest (14) |
| TestRail Suite | Master (21) |
| Target Section (Manual Tests) | 65470 |
| Release Threshold | 20 |

**⚠️ Target Section:** Verify this ID in your TestRail project. Navigate to Settings → Sections → find your manual tests section and confirm its ID.

## Source Sections

List all the TestRail section IDs for your app that may need updates:

| Section Name | ID | Purpose |
|--------------|-----|---------|
| Root / Main tests | `<ID>` | Primary test cases |
| Capabilities | `<ID>` | Feature capability tests |
| Edge cases | `<ID>` | Edge case tests |
| (Add more as needed) | | |

**When running the skill, include the IDs in `$SourceSectionIds` as a comma-separated list:**
```
$SourceSectionIds: <ID1>,<ID2>,<ID3>
```

## Release IDs

Use these to set the `$ReleaseThreshold` parameter:

| Release | ID | Status |

**⚠️ Release IDs may vary:** Verify these in your TestRail project. Navigate to Releases in your project to confirm the IDs match your environment.

## Example Run

```
$App: YOUR-APP
$SourceSectionIds: <Copy IDs from above>
$TargetSectionId: 65470
$SearchPattern: <YOUR SEARCH>
$ReplacePattern: <YOUR REPLACEMENT>
$RefToAdd: <JIRA-KEY or leave empty>
$ReleaseThreshold: 20
$CopyTargetRelease: null
$DryRun: true
```

1. Copy the above and replace placeholders
2. Run with `$DryRun = true` first
3. Review the log
4. Re-run with `$DryRun = false` when ready
```

## Notes

- **Target Section**: Usually `65470` (Sunflower/Manual tests), but can vary by project. Check your TestRail setup.
- **Release Threshold**: The cutoff for "pre-release" vs "current." Cases with `release_id < threshold` get copied before updating. Adjust based on your release cycle.
- **Release IDs**: These may vary by app. Verify in your TestRail project.
